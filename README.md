# **DesktopPool**

*Play Pool On Desktop!*



**Render a pool game without a window open.**

Available for Windows.



[Download in the Latest Release](https://github.com/Nam1925/DesktopPool/releases)



Download either Python file / EXE file.

**Requirements (Python file):**

* PyQt6 (auto install)



**There are currently 5 color palettes in the original source code:**

* Rainbow
* Monochrome
* Neon Cyberpunk
* Pastel Dream
* Sunset Gradient

You can add and modify your favorite color palette (Python file only).



**Note: Press ESC to close the program.**
